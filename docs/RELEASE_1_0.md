# MineHost 1.0.0

## Новый интерфейс

Начальный экран содержит список серверов и общие настройки. Нажмите название или «Управлять» на карточке: появятся обзор и боковые разделы выбранного сервера. Возврат к «Мои серверы» закрывает рабочее пространство. Название и ядро выбранного сервера видны в меню и заголовке.

- Paper и Purpur: «Плагины». Fabric, Forge и NeoForge: «Моды» и «Модпаки». Vanilla не поддерживает эти дополнения. Проверка JAR на backend также учитывает ядро; скрытая вкладка не заменяет проверку совместимости.
- Вкладки дополнений содержат установленные файлы, поиск, загрузку JAR с компьютера, включение/выключение, обновление, удаление и просмотр описателя (plugin.yml, fabric.mod.json или соответствующий TOML). Описатели показываются текстом и не исполняются. Каталоги Modrinth/CurseForge остаются встроенными; CurseForge требует одобренного API-доступа владельца.
- «Миры» → «Загрузить свой мир»: выбор папки с level.dat или ZIP, имя новой папки и загрузка. Исходные файлы не перемещаются; существующий мир не заменяется. После загрузки нажмите «Выбрать» в списке для следующего запуска. Нужны остановленный сервер, совместимая версия мира и сохранённый источник. Лимиты 32 GiB/100000 файлов, ссылки и исполняемые файлы запрещены.
- «playit.gg»: настройка одной кнопкой, запуск/отключение общего агента, состояние, адреса и копирование прямо в приложении. Первый вход/подтверждение аккаунта остаются в браузере. Отключение общего агента закрывает все назначенные ему туннели. [Инструкция](PLAYIT_AUTO.md).

## Важное изменение удаления

«Удалить сервер» теперь стирает данные окончательно. Окно требует точное имя и отдельное подтверждение необратимости. Удаляются servers/UUID, локальные backups/UUID-*, старые trash/UUID-* и записи профиля/его истории/расписания/сетевых предпочтений. Общая Java, общий кэш и файлы других серверов не удаляются. Ссылки внутри сервера удаляются как ссылки без перехода к внешнему содержимому.

Остановите сервер и управляемый playit, дождитесь файловых/облачных операций. Облачные копии Google Drive, туннели аккаунта и внешние сетевые правила требуют отдельного удаления в соответствующем разделе/кабинете. При ошибке файловой системы профиль остаётся в списке: часть файлов уже может быть удалена; закройте использующие их программы и повторите удаление. Резервные копии этого профиля удаляются тоже — сначала экспортируйте нужную копию вне каталога MineHost.

## Проверки выпуска

Сборка, Rust fmt/Clippy/tests, TypeScript, frontend, проверка скачивания и запуск пакета выполняются исключительно в GitHub Actions на Windows. Проверка интерфейса также запускается в облаке: реальный Chromium с имитацией Tauri-команд проверяет переходы между профилями, совместимость вкладок, выбор файлов/папок, просмотр описателя, управление playit и подтверждение удаления. PNG доступны в артефакте MineHost-ui-checks. Эти UI-проверки не запускают реальный Minecraft и не удаляют пользовательские файлы. Rust-тесты отдельно проверяют реальные временные файлы, импорт папки, постоянное удаление и сохранность цели junction.

После установки проверьте на тестовом профиле: переключение Paper/Fabric/Vanilla; импорт своего JAR и просмотр; загрузку копии мира из папки и ZIP; start/stop playit и подключение друга; отмену окна удаления и окончательное удаление ненужного профиля. Настоящее удаление проверяйте только на ненужных данных. Обновление поверх 0.9.1 должно сохранить имеющиеся профили без автоматического запуска.

1.0 публикуется как обычный стабильный GitHub Release с setup, EXE и SHA256SUMS.txt. Подпись остаётся отложенной по решению владельца. Успешная облачная проверка не означает, что реальные игровые сценарии новой версии уже вручную пройдены.
