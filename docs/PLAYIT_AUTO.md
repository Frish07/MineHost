# Настройка playit одной кнопкой — 0.9.1

Откройте выбранный профиль → «Подключение» → «Настроить playit и получить адрес». Подтвердите скачивание/запуск агента и интернет-доступ. MineHost проверяет официальный standalone playit 2.0.2 по SHA-256; Rust, Node.js, Build Tools и другие средства разработки не устанавливаются. Minecraft-сервер запускается отдельно после EULA и подготовки Java runtime.

Если агент ещё не привязан, открывается браузер. Войдите в свой аккаунт playit и подтвердите добавление агента. MineHost автоматически вызывает claim/setup каждые 3 секунды и обменивает подтверждение на ключ, поэтому вручную нажимать «Проверить привязку» не нужно. Пароль аккаунта MineHost не запрашивает. Ключ находится в Windows Credential Manager и не передаётся интерфейсу.

Затем запускается агент, создаётся бесплатный Minecraft Java TCP-туннель к `127.0.0.1:<порт профиля>` либо используется подходящий существующий. Платные регионы, домены и другие покупки не выбираются. После выделения адреса и подтверждения точного туннеля работающим агентом MineHost сохраняет способ подключения playit и показывает адрес с кнопкой копирования. Обычно это доменное имя с портом, а не персональный выделенный IP. Друзья вводят весь выданный адрес в Minecraft Java. Дождитесь Done сервера; получение адреса ещё не доказывает внешнюю доступность — проверьте с другого подключения.

## Ограничения и восстановление

- Аккаунт, подтверждение email, лимиты бесплатных туннелей и доступность сервиса контролирует playit. MineHost не обходит ограничения и не покупает Premium. При отказе откройте «Ручная настройка и управление агентом» → «Кабинет и туннели».
- Агент, ранее привязанный версией 0.9.0, имеет тип assignable. Подходящий готовый туннель можно использовать автоматически. Для автоматического создания нужен self-managed агент, как в официальном Minecraft-плагине playit. Если старый агент не имеет туннеля: остановите его, выберите «Забыть привязку» и заново запустите настройку. Облачные агенты и туннели старого аккаунта не удаляются; проверьте и уберите ненужные через кабинет.
- Повторная настройка сначала проверяет подходящие активные Minecraft Java TCP-туннели. До запроса создания в SQLite сохраняется маркер профиля/агента/порта. После таймаута или неоднозначного ответа запрос создания не повторяется вслепую: MineHost ищет результат в данных агента. Если адрес долго не появляется, проверьте кабинет; подходящий туннель можно настроить там вручную. Явный отказ API снимает маркер для повторной попытки после исправления причины. После подтверждённого создания сохраняется ID; удалённый/отключённый вручную туннель не заменяется автоматически.
- Отмена не отзывает уже отправленный запрос. Созданный облачный туннель остаётся. Агент, запущенный этой настройкой, останавливается после текущего шага; ранее работавший общий агент продолжает работу. Для закрытия всех управляемых туннелей есть «Отключить интернет-доступ playit».
- Один агент обслуживает все назначенные ему туннели. Его запуск публикует их все. Служба Windows, автозапуск, правила Firewall и настройки роутера автоматически не меняются. При смене порта старые облачные туннели автоматически не удаляются.
- Время ожидания браузерной привязки ограничено примерно 10 минутами плюс длительность сетевых запросов; выделение туннеля также ограничено. Повторная попытка сохраняет существующий результат. Сторонняя служба playit не управляется MineHost.

## Ручная приёмка

1. На чистой привязке нажать кнопку один раз, проверить прогресс загрузки и автоматическое обновление страницы claim, войти и подтвердить браузерную привязку. Не нажимать ручную проверку.
2. Убедиться, что бесплатный туннель указывает на порт выбранного профиля и адрес сохранился в верхней части «Подключение». Проверить копирование адреса и подключение друга после Done.
3. Повторить настройку: новый дубликат не должен появиться. Перезапустить MineHost, повторить с сохранённой привязкой и проверить повторное использование.
4. Проверить отмену в браузере и во время выделения, сетевую ошибку, лимит/неподтверждённый email, ранее работающий агент и второй профиль. Проверить, что чужие порты/UDP/отключённые туннели не выбираются как адрес текущего сервера.
5. Отключить playit: публичные туннели этого агента должны стать недоступны. Сам Minecraft остаётся запущенным локально.

Автотесты моделируют переходы настройки и проверяют фильтрацию адресов; реальный аккаунт, браузерное согласие и внешний игровой клиент в CI не используются.
