# CurseForge — доступ и ограничения

В 0.8.0 добавлена отдельная вкладка CurseForge в «Моды и плагины». Она использует официальный API v1, собственную настройку ключа и общий механизм проверенной установки MineHost. Работоспособность приложения, Modrinth и ручного импорта не зависит от наличия CurseForge-доступа.

## Доступ

Общий ключ в исходники, EXE, GitHub Actions или Release не встроен. Использовать ключи чужих приложений нельзя. Для работы API нужен доступ, выданный для MineHost и разрешающий предполагаемое использование. Общие API-условия запрещают передачу ключей третьим лицам; для публичного распространения сначала согласуйте модель доступа с CurseForge. Наличие экрана настройки не означает, что приложение уже одобрено платформой.

1. Владелец проекта самостоятельно подаёт заявку по [инструкции CurseForge](https://support.curseforge.com/support/solutions/articles/9000208346-about-the-curseforge-api-and-how-to-apply-for-a-key), указывая реальное приложение и способы использования API/CDN.
2. Условия и разрешения проверяет владелец: [API Terms](https://support.curseforge.com/support/solutions/articles/9000207405-curse-forge-3rd-party-api-terms-and-conditions). MineHost не подаёт заявку, не принимает условия от вашего имени и не обещает выдачу ключа.
3. После одобрения сохраните свой ключ одной строкой в UTF-8 TXT. В MineHost выберите «CurseForge» → подтвердите право использования → «Импортировать ключ из TXT» → «Проверить доступ».
4. Ключ хранится в Windows Credential Manager. Импортированный TXT остаётся у владельца; MineHost его не удаляет. Не отправляйте ключ в чат, не коммитьте TXT и не распространяйте его с установщиком.

Настройка не требует локальных Rust, Cargo, Node.js, JDK или Visual Studio. До неё отображается реальное состояние «не настроен», а не фиктивный каталог. Без API можно открыть официальный сайт, скачать разрешённый файл через браузер и воспользоваться обычным импортом JAR.

Ключ передаётся в `x-api-key` только на фиксированный API-хост и проверенные файловые CDN-узлы. На переадресациях хост проверяется заново до отправки ключа. Query-параметры для ключей, неизвестные CDN, HTTP и учётные данные в URL запрещены. Сайт проекта открывается отдельно в системном браузере без API-ключа. Изображения загружаются отдельным клиентом без ключа.

«Забыть ключ» удаляет локальную запись, но не отзывает ключ на CurseForge; уже начатые запросы могут завершиться. Каталожные метаданные и описания не пишутся в постоянный кэш. Локальный реестр установленных файлов хранит только происхождение, project/file IDs, имя файла и версию для управления установленными пользователем дополнениями. Модель такого использования также должна соответствовать выданному разрешению. Запросы ограничены по размерам, страницам и числу обращений в одной операции.

## Каталог и установка

Классы Mods и Bukkit Plugins определяются из ответа API для Minecraft. Если ключ не открывает нужный класс, показывается ошибка и остаётся ручной импорт; MineHost не подменяет результаты другим каталогом. Фильтры: Minecraft-версия, Forge/Fabric/NeoForge, категория, сортировка и страницы по 20 проектов. Bukkit-плагины дополнительно проверяются по JAR-дескриптору Paper/Bukkit; Fabric/Forge-файлы в plugins не устанавливаются.

Предлагаются только доступные стабильные JAR с совпадающими тегами Minecraft/loader и допустимым статусом публикации. Beta/alpha, early access, server-pack ZIP и дополнительные файлы не смешиваются с основным JAR. Лимит одного JAR — 256 MiB. CurseForge не предоставляет универсальную гарантию server-side: проверьте описание и назначение мода. Клиентские Fabric-моды отклоняются по environment. Дескриптор Forge/NeoForge сам по себе не доказывает, что мод работает на сервере.

Описание отображается как текст, HTML/скрипты не исполняются. До шести галерейных изображений проходят проверку хоста, размера и формата PNG/JPEG/WebP. Исходная страница проекта доступна отдельной кнопкой.

Перед установкой показывается полный план, включающий обязательные зависимости. Optional, tool, embedded и include не скачиваются автоматически. Проверяются явные несовместимости плана и включённых записей CurseForge. Ограничения: 32 проекта, глубина 16, 128 включённых записей для обратной проверки конфликтов, до 500 подходящих версий проекта. Это не общий solver идентичности модов между CurseForge, Modrinth и ручными файлами; одинаковые названия проектов не используются как доказательство тождественности. Отсутствие метаданных ручных файлов не считается отсутствием конфликта.

План заново получается перед установкой. Изменение file IDs, хешей, размеров или разрешения прямой загрузки требует нового просмотра. Все JAR сначала скачиваются/копируются в staging, проверяются по размеру, SHA-1 (либо MD5, если SHA-1 отсутствует) из API и дескриптору. Это проверка целостности, не антивирус и не цифровая подпись автора. После проверки всего набора выполняется замена с резервными файлами и откатом при ошибке. Для установки и обновления сервер должен быть остановлен; требуется согласие на выполнение стороннего кода.

Установленные дополнения имеют отдельное происхождение `modrinth`/`curseforge`. Старые записи без поля провайдера читаются как Modrinth. Обновление идёт через исходного провайдера; включение, отключение и удаление остаются в общем списке. Совпадение имён файлов между провайдерами не разрешает незаметную замену чужого файла.

## Запрещённое прямое распространение

Если автор выставил `allowModDistribution=false` либо API не вернул download URL, MineHost не строит CDN-адрес по числовому ID и не ищет обходной API. В плане появляется ручной шаг: открыть проект, получить выбранный файл разрешённым способом и выбрать JAR. Проверяются точные размер и хеш из метаданных. Несовпадающий локальный файл не меняет уже установленные JAR.

Авторизация файлового CDN изменилась в 2026 году: [официальное объявление](https://blog.curseforge.com/introducing-api-key-authentication-for-curseforge-file-downloads/). Интеграция отправляет заголовок ключа при разрешённой загрузке, а не пытается обойти HTTP 401/403. Если API/лицензия не позволяют доступ, автоматическая установка остаётся недоступной.

CurseForge modpack ZIP в этом этапе не импортируется. Для модпаков уже поддерживается Modrinth `.mrpack`; произвольные установочные скрипты не запускаются.

## Проверки

Actions проверяет схему/параметры запросов на локальном HTTP fixture, заголовок авторизации, обязательные зависимости, границы Minecraft/loader, запрет распространения, хеши ручного JAR и сохранность ранее установленных файлов при ошибке. Регрессионный тест выполняет реальную загрузку и установку Modrinth. Эти проверки не являются одобрением CurseForge или проверкой реального ключа. После получения разрешения владелец отдельно проверяет доступ, каталог, CDN-загрузку, обновление и ручной шаг для ограниченного проекта. Без ключа эти сценарии не отмечаются выполненными.

Официальная спецификация: [CurseForge REST API](https://docs.curseforge.com/rest-api/).
