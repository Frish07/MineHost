# Ручная приёмка MineHost 0.9 перед 1.0

Сначала используйте отдельный профиль и копию мира. Установка Rust, Cargo, Node.js, Visual Studio или JDK для MineHost не нужна. Java runtime для самого Minecraft обнаруживается или загружается с отдельным согласием. Подпись отложена на неопределённый срок; предупреждение SmartScreen у неподписанного установщика возможно.

## Установка и сохранность данных

- Скачать setup из Releases и сверить SHA-256 с SHA256SUMS.txt. Установить поверх предыдущей версии и проверить список профилей, миры, историю и настройки. Обновление не означает автоматический запуск серверов.
- Создать два профиля с разными портами. Проверить EULA, обнаружение/загрузку Java, скачивание стабильного Paper с прогрессом, запуск до Done, подключение и корректный stop. При необходимости повторить на реально используемом Forge/NeoForge/Fabric/Purpur/Vanilla.

## Новые настройки

- На остановленном сервере открыть «Настройки сервера»: проверить сложность, PvP, whitelist, режим игры, максимум игроков, дистанции, spawn protection, полёт и force gamemode. Сохранить, запустить и проверить фактическое поведение.
- Сохранить русский многострочный MOTD и эмодзи. Перечитать, затем проверить отображение клиентом. Комментарии и неизвестный параметр должны сохраниться; предыдущий файл находится в .minehost/file-backups.
- Попробовать порт другого профиля: сохранение должно отказать без изменения файла. Для свободного порта требуется отдельное подтверждение. Проверить подключение по новому порту после запуска. Прежние Firewall/UPnP/playit/DNS не переписываются автоматически: проверить и убрать старые правила в «Подключение».
- Загрузить настройки, изменить файл внешним редактором, затем попытаться сохранить старую форму: должно потребоваться перечитывание. Проверить подтверждение отбрасывания изменений при перечитывании/смене редактора.
- Расширенный редактор поддерживает Java escapes и продолжения строк. Дубли ключей, неверный Unicode, online-mode=false, дополнительные сетевые слушатели и опасное имя мира отклоняются. Менять файл во время работы Java не следует.

## Согласованные копии

Полный архив создаётся при остановленной Java. Это обслуживание с временным отключением игроков, а не горячая копия без простоя. Согласованность предполагает, что сторонние программы в это время не изменяют файлы профиля.

- На запущенном сервере изменить мир, подтвердить обслуживание и перезапуск. Проверить этапы stop → подтверждённый корректный выход Java → ZIP → повторный запуск. После запуска дождаться Done и проверить изменения мира. Шкала ZIP показывает исходные обработанные байты, а не размер сжатого архива или оставшееся время.
- Снять флажок повторного запуска: после копии сервер должен оставаться остановленным. Для изначально остановленного профиля копирование никогда само его не запускает.
- Проверить отмену во время ожидания и архивации: отправленный stop не отменяется, автоматического возобновления не будет, частичный ZIP удаляется. Не путать отмену со снятием уже отправленной команды остановки.
- Если Java не завершилась за 180 секунд либо завершилась с ошибкой, копирование и автоматический запуск запрещаются. Принудительного kill нет. Ошибка ZIP после подтверждённого корректного выхода допускает выбранное возобновление; UI показывает ошибку и факт повторного запуска отдельно.
- Восстановить копию в тестовом профиле совместимой версии; проверить полный сервер и отдельный мир. Перед восстановлением создаётся защитная копия. Проверить, что при обслуживании нельзя одновременно редактировать/удалять профиль или запускать второй процесс.
- Расписание по умолчанию ждёт остановки. Отдельный флажок разрешает обслуживание работающего сервера и повторный запуск с отключением игроков. Расписание действует только при открытом MineHost; минимум 1 час. Оставить приложение открытым и проверить реальное наступление срока, retention и, если настроен Google OAuth, загрузку/скачивание/восстановление Drive. Закрытие с активной операцией должно блокироваться.

## Остальная приёмка и отчёт

Проверить моды/плагины, обязательные зависимости и обновления Modrinth, импорт .mrpack, галереи/категории, историю подключений и перенос Nether/End на тестовых копиях. CurseForge требует одобренного API-доступа; без него проверить инструкцию и доступность остальных функций, не вводя случайный ключ. Playit, DNS, UPnP, Firewall/UAC и Google Drive проверяются с реальными настройками владельца по соответствующим руководствам.

Проверить светлую/тёмную тему, русский/английский язык, узкое окно, масштаб Windows, клавиатурную навигацию, отмены, смену профиля и повторное открытие вкладок. Скрытые панели не должны продолжать видимый опрос прогресса; мониторинг не запрашивает spark автоматически.

Для каждого замечания записать версию Windows/MineHost, ядро и Minecraft, шаги, ожидаемый/фактический результат и текст ошибки. Удалить токены, ключи и личные адреса из логов. После этой приёмки планируется исправление замечаний и финальная доработка 1.0. Этот документ не утверждает, что ручные сценарии уже пройдены.
